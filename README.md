# Bastian's Suite

Addons for **WoW Forever** and **retail**: quests, map, browser, gold, routes and a book of gold
strategies. Every app works on its own, and together they work as one system.

**Website:** [bastians.dev/wow](https://bastians.dev/wow/)
· **Bugs and ideas:** [Issues](https://github.com/drstreit/Bastians-WoW-Forever-Addons/issues/new/choose)

| App | What it does | Command |
|---|---|---|
| Core | settings hub, launcher, one search over everything, colour themes | `/bastians`, `/bs` |
| Quests | quest log, what to do next for your level and zone, chains, attunements, tracker | `/bq` |
| Map | world map and minimap pins for quests, NPCs, vendors, trainers and gathering spots | `/bmap` |
| Map Art | the painted overview map for Bastian's Map | |
| Browser | look up any quest, NPC, item or zone, everything linked | `/bb` |
| Gold | prices from your scans and vendor visits, farm spots, your gold over time | `/bgold` |
| Route | the way there by flight path, boat, zeppelin, tram, portal or hearthstone | `/broute` |
| Strategies | Bastian's Gold Rumours, a book of gold strategies with today's prices (WoW Forever) | `/bbook` |
| Data | the game data behind every app, built per client and updated daily | |

## Install

From launch day (4 November 2026) on CurseForge: install **Bastian's Suite**, and the CurseForge
app installs **Bastian's Data** with it. The first time, restart the game fully: `/reload` does not
find new addons. Optional companions: TomTom (both clients), Questie and Spoken Quests (WoW
Forever).

## Building from source

The addons in `addons/` are plain Lua 5.1. Their data packs are generated by the Python 3.14
pipeline in `pipeline/` from the source addons named below and from files of an installed WoW
client, so a build needs a local client. `python -m pytest` runs the tests, the addon code
included (on Lua 5.1 against a WoW API mock).
